# Automotive-AR-Navigation-Systems
This is a project that showcases the Threat Analysis of an AR navigation system for an automotive device using the STRIDE model. 

Each LLM has its own separate folder, which contains the Excel files with the results of the STRIDE-based analysis.

The Medini Result folder contains the Excel file with all the threats generated by the expert tool.

The Prompts folder contains a file that has all the prompts we used for the LLMs
